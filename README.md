# Два дома в Сургуте — лендинг посуточной аренды

Готовая статика: чистый HTML/CSS/JS, без сборки, CMS и бэкенда. Открывается двойным кликом по `index.html`.

```
surgut-houses/
├─ index.html          главная: первый экран, карточки, галереи, условия, цены, карта, форма, FAQ
├─ privacy.html        политика обработки персональных данных (152-ФЗ)
├─ assets/
│  ├─ css/style.css    стили, светлая и тёмная тема по системной настройке
│  └─ js/
│     ├─ config.js     ВСЕ цифры и контакты — меняются здесь
│     └─ main.js       галерея, форма, подстановка значений
└─ images/             фото (сейчас — заглушки WebP + JPG)
```

## Как загрузить на хостинг

Залейте **содержимое** папки `surgut-houses` в корень сайта (`public_html`, `www` или аналог). `index.html` станет главной страницей. PHP, база данных и сборка не нужны. Для локальной проверки достаточно открыть `index.html` в браузере.

## Фотографии

Положите файлы в `images/` **с теми же именами** и в двух форматах: `.webp` (основной) и `.jpg` (фолбэк). Кадр в обоих форматах одинаковый.

| Файл | Что на фото | Размер |
|---|---|---|
| `hero-facade` | фасад для первого экрана (лучше сумерки, тёмный низ кадра) | 1920×1080 |
| `og-facade.jpg` | картинка для соцсетей, только JPG | 1200×630 |
| `map` | скриншот карты с меткой | 1200×900 |
| `aframe-facade` | A-frame: фасад | 1600×1200 |
| `aframe-living` | A-frame: гостиная | 1600×1200 |
| `aframe-bedroom` | A-frame: спальня | 1600×1200 |
| `aframe-window` | A-frame: вид из окна | 1600×1200 |
| `aframe-evening` | A-frame: вечерняя подсветка | 1600×1200 |
| `barnhouse-facade` | Barnhouse: фасад | 1600×1200 |
| `barnhouse-living` | Barnhouse: гостиная | 1600×1200 |
| `barnhouse-bedroom` | Barnhouse: спальня | 1600×1200 |
| `barnhouse-window` | Barnhouse: вид из окна | 1600×1200 |
| `barnhouse-evening` | Barnhouse: вечерняя подсветка | 1600×1200 |

Пропорции важны: галереи 4:3, первый экран 16:9. Если фото другого формата — обрежьте по центру, а не растягивайте. Конвертация: [squoosh.app](https://squoosh.app) (WebP, качество 75–80) или ImageMagick:

```
magick original.jpg -resize 1600x1200^ -gravity center -extent 1600x1200 -quality 82 aframe-living.jpg
magick aframe-living.jpg -quality 79 aframe-living.webp
```

Если WebP сделать негде — удалите в `index.html` строку `<source srcset="…webp" type="image/webp">` у нужного фото, останется JPG. Размеры в разметке (`width`/`height`) уже заданы, вёрстка не дёргается; менять их не нужно.

## Цены, телефон, WhatsApp

Всё в одном файле — `assets/js/config.js`, сверху вниз:

- **Контакты:** `phoneText` (как видно на сайте), `phoneRaw` (для звонка), `whatsapp` (только цифры: `79001234567`), `telegram` (ник без `@`), `email`.
- **Реквизиты:** `legalName`, `inn`, `ogrnip` — подвал, контакты, политика.
- **Цены:** `prices.aframe` и `prices.barnhouse` — `weekday` / `weekend` / `holiday`. Из них автоматически считаются «от … ₽/сутки» в карточках и таблица цен.
- **Дома:** `houses` — гости, спальни, площадь.
- **Условия:** `checkin`, `checkout`, `minNights`, `deposit`, `pets`, `cancel`.
- **Адрес и дорога:** `addressShort`, `addressFull`, `coords`, `minutes`.
- **Доп. услуги:** массив `extras` — строки таблицы «Услуги / Цена / Примечание».

После правки обновите страницу. Подписи `PLACEHOLDER` в комментариях — то, что нужно заменить. Значения в HTML оставлены как резерв на случай отключённого JS; менять их не обязательно.

## Что ещё поменять в `index.html`

- **«Что внутри»** (`id="inside"`) — список с чекбоксами: удалите лишние `<li>`, у нужных оставьте `checked`.
- **«Условия»** (`id="rules"`) — правила проживания текстом.
- **FAQ** (`id="faq"`) — вопросы и ответы.
- **Карта.** Сейчас — картинка-заглушка. Либо замените `images/map.jpg` и `map.webp` скриншотом с меткой, либо вставьте Яндекс.Карту: в `<div class="loc__map">` удалите `<picture>` и `<span class="loc__map-note">`, вставьте код из «Яндекс.Карты → Поделиться → Встроить карту»:

```html
<iframe src="https://yandex.ru/map-widget/v1/?ll=73.396%2C61.254&z=13&pt=73.396,61.254,pm2rdm"
        width="100%" height="420" style="border:0;display:block"
        loading="lazy" title="Карта: расположение домов"></iframe>
```

- **SEO.** В `<head>` замените `example.ru` в `canonical`, `og:url` и в микроразметке; в JSON-LD обновите телефон, адрес, координаты и ссылки на фото. После публикации добавьте сайт в Яндекс.Вебмастер и счётчик Яндекс.Метрики перед `</body>`.

## Форма заявки

Бэкенда нет: после проверки полей JS собирает текст и открывает WhatsApp (`wa.me`) с готовым сообщением. Кнопка Telegram открывает чат, а текст заявки копируется в буфер — остаётся вставить. Проверяется: имя, телефон, дом, даты (выезд позже заезда), число гостей (не больше вместимости дома) и согласие по 152-ФЗ. После отправки показывается блок с текстом заявки и кнопками — он же спасает, если браузер заблокировал новое окно.

## Проверьте перед публикацией

- [ ] Все `PLACEHOLDER` заменены (поиск по файлам слова `PLACEHOLDER`).
- [ ] Фото лежат в `images/` в WebP и JPG, имена совпадают с таблицей.
- [ ] Телефон, WhatsApp и Telegram открываются с телефона.
- [ ] Текст политики в `privacy.html` проверен юристом и дополнен вашими данными.
- [ ] Форма протестирована на телефоне, заявка приходит в WhatsApp.

## Каких данных не хватает (стоят заглушки)

1. **Название проекта** — сейчас «Два дома в Сургуте».
2. **Цены** за сутки: будни / выходные / праздники по каждому дому; что считаете праздниками.
3. **Депозит**, минимальный срок, условия отмены и размер предоплаты.
4. **Животные**: можно или нет, доплата.
5. **Адрес или район**, координаты; минуты до аэропорта, центра и вокзала.
6. **Телефон, WhatsApp, Telegram, e-mail**, часы ответа.
7. **Реквизиты**: ИП или самозанятый, ИНН, ОГРНИП.
8. **Вместимость, спальни, площадь** по каждому дому (сейчас 4/2/45 и 6/3/90).
9. **Оснащение**: что реально есть — баня, мангал, стиральная машина, детская кроватка и т. д.
10. **Домен** для `canonical` и Open Graph.
11. **Фото**: по 5 кадров на дом (фасад, гостиная, спальня, вид из окна, вечерняя подсветка) + фото бани/мангала, если нужны в галерее.
