# Два дома в Сургуте — лендинг посуточной аренды

Статический сайт: HTML/CSS/JS без сборки, CMS и бэкенда. Открывается двойным кликом по `index.html` — без интернета и локального сервера.

```
surgut-houses/
├─ index.html          главная: первый экран, выбор домов, условия, форма, контакты
├─ aframe.html         страница A-frame: hero, галерея, баня, цены, удобства, форма
├─ barnhouse.html      страница Barnhouse: hero, галерея, цены, удобства, форма
├─ privacy.html        политика обработки персональных данных (152-ФЗ)
├─ settings.html       настройки: тема, вход администратора, вкладка «Заявки»
├─ assets/
│  ├─ css/style.css    стили; тёмная и светлая тема по системной настройке
│  └─ js/
│     ├─ config.js     ВСЕ цифры, цены и контакты — меняются здесь
│     ├─ main.js       подстановка значений, галерея, форма, микроразметка
│     ├─ settings.js   тема и вкладка заявок на странице настроек
│     └─ theme.js      применяет тему до отрисовки страницы
├─ images/             фото в WebP + JPG, логотипы, favicon
└─ README.md           этот файл
```

## Как загрузить на хостинг

Залейте содержимое папки в корень сайта (`public_html`, `www` или аналог). Главная — `index.html`. PHP, база и сборка не нужны. Для локальной проверки достаточно открыть `index.html` в браузере.

## Как менять цены, телефон, Telegram

Всё в одном файле — `assets/js/config.js`, сверху вниз:

- **Контакты:** `phoneText` (как видно на сайте), `phoneRaw` (для `tel:`), `telegram` (ник без `@`), `max` (номер для поиска в MAX).
- **Админка:** `adminPassword` — пароль для вкладки «Заявки».
- **Оператор:** `legalName` — подвал, контакты, политика.
- **Расположение:** `address.short` / `address.full` / `address.street` (для микроразметки), `minutes` — минуты до аэропорта, центра, вокзала.
- **Условия:** `checkin`, `checkout`, `minNights`, `deposit`, `pets`, `cancel` — блок «Условия» на главной и на страницах домов; часы заезда у Barnhouse берутся из `houses.barnhouse`.
- **Дома:** `houses.aframe` и `houses.barnhouse` — гости, комнаты, площадь, `priceFrom` (цена «от … ₽» в карточке; `null` → «цена по запросу»). У Barnhouse также `checkin`, `checkout`, `address`, `distance` и `extras` (баня, чан, казан, мангал).
- **Цены A-frame:** `prices.tariffs` — два тарифа («Для двоих», «До 6 человек»), в каждом `house` (дом) и `bath` (дом + баня) с ценами `sunThu` (вс–чт), `fri` (пятница), `sat` (суббота); `null` — «по запросу». Из них собираются карточки на `aframe.html`; таблица цен осталась на `barnhouse.html`. `prices.ph: true` оставляет пунктирное подчёркивание (метка «заглушка») — поставьте `false`, когда впишете настоящие цены. Текст под таблицей — `prices.note`.
- **Доп. услуги:** массив `extras` — список на `aframe.html`; у Barnhouse свои `houses.barnhouse.extras`.
- **Текст заявки:** `requestTitle` — первая строка сообщения в мессенджер.

После правки обновите страницу. Заглушки в тексте подчёркнуты пунктиром и имеют подсказку при наведении — это подсказка, где не хватает ваших данных.

## Домен и SEO

- В `index.html`, `aframe.html`, `barnhouse.html`, `privacy.html` замените `https://example.ru/` в `canonical`, `og:url` и `og:image`.
- В `config.js` укажите `site` — из него собирается микроразметка `LodgingBusiness` + `Accommodation` (генерируется скриптом при загрузке страницы).
- `title` и `description` уже заточены под запросы «аренда дома посуточно Сургут», «A-frame Сургут», «барнхаус Сургут».
- После публикации добавьте сайт в Яндекс.Вебмастер и Яндекс.Метрику.

## Карта

На странице Barnhouse карта уже вставлена: Яндекс.Карты находят адрес «СТ № 56 Приозёрное, 462Б» и ставят метку. На главной карты больше нет; для A-frame её можно добавить, когда будет адрес.

Заменить карту можно так: в блоке `<div class="loc__map">` удалите `<picture>` и `<span class="loc__map-note">` (или готовый `<iframe>`) и вставьте код из «Яндекс.Карты → Поделиться → Встроить карту». Если координат нет, работает поиск по адресу:

```html
<iframe src="https://yandex.ru/map-widget/v1/?text=Сургут%2C%20СТ%20Приозёрное%2C%20462Б&z=14"
        width="100%" height="420" style="border:0;display:block"
        loading="lazy" title="Яндекс.Карта: расположение дома"></iframe>
```

## Тёмная и светлая тема

Тема по умолчанию следует системной настройке, переключается на странице «Настройки» (Как в системе / Светлая / Тёмная). Выбор хранится в браузере. Палитра задана переменными в начале `assets/css/style.css`: `:root` — тёмная, `html[data-theme="light"]` — светлая; `theme.js` ставит атрибут до отрисовки. Логотипы переключаются автоматически (`logo-dark.png` на тёмной, `logo-light.png` на светлой).

## Форма заявки

Бэкенда нет: после проверки полей скрипт собирает текст, копирует его в буфер и показывает подтверждение с текстом и кнопкой Telegram. Никуда автоматически не перекидывает. Проверяется: имя, телефон, дом, даты (выезд позже заезда), число гостей (не больше вместимости дома) и согласие по 152-ФЗ.

Копия каждой отправленной заявки сохраняется в localStorage браузера — её видно на странице «Настройки» после ввода пароля.

## Настройки и админка

Ссылка «Настройки» — шестерёнка в шапке и ссылка в подвале. На странице settings.html:

- **Тема:** «Как в системе», «Светлая», «Тёмная». Выбор хранится в браузере и применяется до отрисовки страницы (	heme.js).
- **Заявки:** вкладка появляется после ввода пароля из config.js (dminPassword, сейчас 18042013). Там же кнопки «Принять» и «Отклонить» — статус меняется и сохраняется.

Важные ограничения:

- **Пароль не защищает данные.** Он лежит в config.js и виден в исходниках любому. Это быстрый «свой» экран, а не авторизация.
- **Вкладка показывает только заявки этого браузера.** Статический сайт не получает данные с чужих устройств: посетитель сам отправляет текст заявки в Telegram или сообщает по телефону. Чтобы собирать заявки в одном месте, нужен внешний сервис (Telegram-бот, Google Таблицы, Formspree) или бэкенд.

Форма есть на главной и на обеих страницах домов. Если меняете поля или тексты, правьте все три файла: `index.html`, `aframe.html`, `barnhouse.html`.

## Шрифт

Используется системный шрифт (Segoe UI / SF / Roboto), `Manrope` — первый в списке, если установлен. Сайт работает без интернета. Если хотите подключить Manrope с Google Fonts, добавьте в `<head>` каждой страницы:

```html
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;600;700;800&display=swap" rel="stylesheet">
```
